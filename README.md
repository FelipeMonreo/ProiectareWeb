# Proiectare Web

Repository realizat pentru disciplina **Proiectare Web**, care conține lucrările de laborator dezvoltate progresiv folosind **HTML, CSS și JavaScript**.

Proiectul pornește de la o pagină personală de prezentare și este extins de la un laborator la altul cu funcționalități noi de interfață și interactivitate.

## Structura repository-ului

```text
ProiectareWeb/
├── laborator-1/
├── laborator-2/
├── laborator-3/
└── README.md
```

Fiecare laborator conține propria versiune a proiectului, împreună cu fișierele CSS, JavaScript și resursele necesare.

## Laboratorul 1

Prima versiune a paginii personale de prezentare.

Conține:
- structură semantică HTML;
- secțiune de prezentare personală;
- informații despre educație;
- hobby-uri și informații suplimentare;
- imagine de profil;
- formular de contact;
- stilizare CSS;
- primele elemente de JavaScript.

Structură principală:

```text
laborator-1/
├── css/
├── imagine/
├── js/
└── index.html
```

## Laboratorul 2

Extinde proiectul realizat în laboratorul anterior prin introducerea unor funcționalități JavaScript suplimentare.

Funcționalități adăugate:
- comutare între **Light Mode** și **Dark Mode**;
- validarea formularului de contact;
- afișarea feedback-ului pentru formular;
- buton **Back to top**;
- interactivitate suplimentară în pagină.

Structură principală:

```text
laborator-2/
├── css/
├── imagine/
├── js/
└── index.html
```

## Laboratorul 3

Continuă dezvoltarea proiectului și adaugă lucrul cu date și colecții JavaScript.

Funcționalități suplimentare:
- secțiune nouă pentru proiecte;
- generarea dinamică a listei de proiecte;
- prelucrarea datelor cu JavaScript;
- afișarea unui rezumat al proiectelor;
- păstrarea funcționalităților realizate în laboratoarele anterioare.

Structură principală:

```text
laborator-3/
├── Data/
├── css/
├── imagine/
├── js/
└── index.html
```

## Tehnologii utilizate

- **HTML5** – structurarea paginilor;
- **CSS3** – stilizare și aspect vizual;
- **JavaScript** – interactivitate și manipularea dinamică a conținutului;
- **Git & GitHub** – versionarea și organizarea proiectului.

## Rularea proiectului

Repository-ul nu necesită instalarea unor dependințe externe.

1. Clonează repository-ul:

```bash
git clone https://github.com/FelipeMonreo/ProiectareWeb.git
```

2. Intră în directorul proiectului:

```bash
cd ProiectareWeb
```

3. Deschide fișierul `index.html` din laboratorul dorit într-un browser.

Exemplu:

```text
laborator-3/index.html
```

Pentru o experiență mai bună în timpul dezvoltării se poate folosi extensia **Live Server** din Visual Studio Code.

## Scopul proiectului

Scopul repository-ului este exersarea conceptelor fundamentale de dezvoltare web și construirea progresivă a unei aplicații front-end, pornind de la structură HTML și stilizare CSS până la introducerea interactivității și manipulării datelor cu JavaScript.
